## 📚 核心发现

### SkillSeek（arXiv 2609.38822）
- **现象**：Anthropic Agent Skills 池 >23 万 SKILL.md，瓶颈从"创作"转移到"挑选"
- **机制**：经典两阶段 IR pipeline（BM25 / BGE-base 双编码器 → small cross-encoder → MCP 暴露）
- **核心洞察**：**first-stage recall ceiling** 解释模式——BM25 单独就能 cover 4 个 setting 里的 3 个；剩下 1 个用 small cross-encoder 补差
- **数字**：SkillsBench 89 任务上 observed parity，cost **$51.30 → $27.54**（与 no-skill baseline 只差 $0.50）

### CAMG（arXiv 2609.34422）
- **现象**：长程 agent 用 RL 学 memory 失败，因为"预定义 memory tool API"在 base model 预训练之外，必须从零学
- **机制**：4 环境（Shop/Coding/DeepResearch/AutoResearch）+ shell + 跨 episode 工作区 + async PPO
- **核心洞察**：让 agent **用 base model 已会的 file ops 当 memory**，从下游 task reward 直接 end-to-end 学
- **数字**：**CAMG-RL-4B 对标 Qwen3.5-35B-A3B（≈9× 大）**，9B 对标 122B（≈13× 大）
