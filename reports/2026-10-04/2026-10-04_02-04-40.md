## 📚 三个主题的核心机制

### 主题1: EvoCUE — 把 agent 显式建模成 state-machine controller
- 节点 = 模型/工具调用，边 = 控制流
- 每个 learned update 含 3 元数据: **what + where + when**（applicability rule）
- 评测: 最小 AppWorld controller 学到正确 convention → Test-Normal/Challenge 双涨- **核心引用**："self-evolving agents should place experience inside the control flow, rather than only store it as text"

### 主题2: SAGE — 统计门控防 regression
- Naive gate 失败: (a) 平均涨但已解 items 被打破 (b) Optimizer's Curse → 极值 upward-biased
- SAGE: per-item paired + one-sided paired test（McNemar），只 commit wins 显著多于 losses 的 edit
- 实证: 20 个设置里 **19 个 regression rate ↓**,1 个持平；**20/20 最终得分最高**
- **核心引用**："commits an edit only when its wins are statistically reliable against its losses"

### 主题3: SelfSearch — 无奖励自搜
- Terminal-Bench 2.1: agent 个人 +11.2pp
- SWE-bench Multilingual: success +5pp, cost -38.5%
- DeepSeek V4 Flash **$4.03** search cost match Codex harness **82.0%**
- **核心引用**："agents modify themselves using records of previous self-improvement episodes... Without downstream reward signals during search"
