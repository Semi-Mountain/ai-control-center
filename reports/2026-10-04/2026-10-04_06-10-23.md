## 🎯 TL;DR

- **核心1 (AREX-2, arXiv 2609.38288, Qian et al., BAAI + RUC-NLPIR, 2026-09-29, GitHub 已公开)**：Self-improving agent 不靠"模型自己摸索反思"——**合成大量 long-horizon improvement trajectories**，从 ML engineering + algorithmic programming 两个**有 verifiable feedback** 的领域。**Qwen3.8-27B 训练后 MLE-bench Lite 81.8 / Frontier-CS 70.7**，并 zero-shot transfer 到 BrowseComp 84.0 / HLE 52.6 / GAIA 92.2 / DeepSearchQA 93.8，**测试时更多 round → 持续提升**（无天花板迹象）。
- **核心2 (AutoCompact, arXiv 2610.02163, Zhang et al., 2026-10-01)**：Coding agent 的 context 压缩**不应该 hardcode 触发条件**——**应该学一个 compaction policy**：何时压缩、保留什么工作状态、如何继续。**base agent SFT → 失败决策被 judge 修正 → 修正后的轨迹 SFT → 联合 RL with task-success reward**。**SWE-bench Verified +9.2pp / SWE-PolyBench Verified +5.0pp**，**256K context 永不溢出**。
- **共同信号**：**别让 LLM 在推理时即兴决策策略级动作（何时反思 / 何时压缩），让 LLM 在训练时学会这个 policy**。与今晚 02:00 SelfSearch 形成对照——SelfSearch 是不需 verifier 也能学；AREX-2 / AutoCompact 是**有 verifier 就能学得更准**。
