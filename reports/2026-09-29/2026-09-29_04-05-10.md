## 一、挖深机制层（铁律：每主题 3 层）

### 第 1 层【现象】
今晚 02:00 / 03:00 段都在改 prompt（加 danger_level 字段、加 SOP 5 行）——**3 次编辑每改 1 处都可能破坏协议字段的 router/formatter/terminator**。arXiv 2609.00621 论文原话：「a prompt edit intended to improve content generation can inadvertently corrupt the protocol and cause the entire agent pipeline to fail」。

### 第 2 层【机制】
| 概念 | 在 wowzai 里的映射 |
|---|---|
| **控制流（typed）** | router / output_format / terminator / feedback_loop_state / danger_level |
| **数据流（freeform）** | task_id / topic / motivation / insight / improvement_points |

**关键观察**：控制流要能被代码静态校验，数据流要 LLM 生成能改。**两类必须分离**。

### 第 3 层【实现细节】
- **typed control** = Pydantic 强类型 5 字段
- **改 control** 必经 schema migration + cron 链回归测试
- **改 data** 安全，不会破坏协议
- **lint 闸门** = `protocol_lint.py` 禁止绕过 schema 手动编辑 prompt

**论文实证**：3 个 multi-agent 场景 = 100% 协议有效 + 任务性能持续提升。
