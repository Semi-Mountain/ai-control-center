## 搜索结果

### 1. STRATA [arXiv:2608.28060] — 用 Mamba 状态空间模型从原始 5 分钟 bar 挖 alpha
- **作者**:Mingju Chen 等 (2026-08-28 v1, 9/14 最新 v4)
- **核心数据**:4 年中盘 A 股约 1000 只,**只用原始 5 分钟 K 线 + 订单簿数据,零手工特征** → rank IC = 0.0728,IR = 1.128,**多空 Sharpe = 12.85**
- **架构创新**:5 分支 stem(4 个因果深度卷积 + 1 个跨场线性对比) + 4 层 selective state-space(Mamba)block + 4 路径 readout
- **关键防御机制**:**所有 IC 都先对 8 个价量风格因子做残差化**,避免模型去"押注常见风格"——这是非常关键的工程经验
- **强制约束**:stem 的卷积核初始化到 sum=0(防止初始就锁定价格水平)
- **数据效率**:24.4 万参数的紧凑模型,不需要 GPU 集群
- **资料来源**:`arxiv.org/abs/2608.28060`

### 2. AlphaAgent [arXiv:2502.16789] — LLM 挖 alpha + 三重正则防衰减
- **作者**:Ziyi Tang 等 (中山大学, 2025-02-24)
- **核心洞察**:**LLM 会过度依赖先验知识,生成同质化因子,加剧 decay**。本文提出 3 个正则化机制:
  1. **AST 原创性正则**:用抽象语法树 (AST) 比对新因子与已有因子库的相似度,强制因子有原创结构
  2. **假设-因子对齐正则**:LLM 评估"市场假设"和"因子语义"是否一致(避免"换皮不换骨")
  3. **复杂度控制正则**:AST 结构深度限制,避免过度工程
- **成果**:在与 LLM-based baseline 对比中胜出,且因子在样本外保持时间更长的预测力
- **为什么对我重要**:**这就是 9/22 03:00 笔记"资金传导"和"产业链轮动"原则的数学化实现**——LLM 把"产业链"知识注入因子设计,再用正则化防止因子被滥用
- **资料来源**:`arxiv.org/abs/2502.16789`

### 3. Hubble [arXiv:2604.09601] — LLM Agent + DSL + AST 沙箱的安全 alpha 工厂
- **作者**:Runze Shi, Shengyu Yan, Yuecheng Cai, Chengxi Lv (2026-03-09)
- **核心架构**:4 个**约束机制**叠加,使 LLM 不会胡乱生成不可执行/不可解释代码:
  | 模块 | 作用 |
  |---|---|
  | **领域专用操作符 DSL** | 把 LLM 输出限制到"动量/波动/价量/反转"等已知算子 |
  | **AST 执行沙箱** | 每个候选因子在 AST 沙箱中运行,**0 运行时崩溃** |
  | **双通道 RAG** | 正向 RAG(喂入历史成功因子) + 负向 RAG(喂入失败案例) |
  | **家族感知选择** | 不是按单一 IC 排序,而是按"家族多样性"挑选,避免同质化 |
- **实证**:3 轮发现 104 个有效因子(US 500 只股票),**前 5 因子被锁定后再验证 10 个月(2025-06 → 2026-03)**,多样性优于仅按 IC 选
- **关键洞察**:**"零运行时崩溃"是可执行系统的硬要求**——这跟 9/23 04:00 我学的"信号处理"是同一类思想:**让生成器有边界,让评估器成为护栏**
- **资料来源**:`arxiv.org/abs/2604.09601`

### 4. AlphaSchema [arXiv:2607.26642] — 把"交易语义"作为 LLM 探索空间
- **作者**:Jingyang Yi, Jian Yang 等 (2026-07-29)
- **核心创新**:把 alpha 挖掘从"公式搜索"提升到"**语义空间搜索**"——每个 schema = {Event, Context, Qualities, Direction, Output}
  - **Event**:触发信号的事件类型(财报/订单流/政策)
  - **Context**:上下文(行业/市值/流动性)
  - **Qualities**:希望考察的量价特征
  - **Direction**:方向预测(多/空/反转)
  - **Output**:输出形式(排序/分位/二分类)
- **LLM 只负责翻译**(schema → 可执行因子),**评估器学习一个 surrogate model 引导搜索**
- **关键数据**:A 股实验显示:alpha 池**预测力强 + 组合表现好**,且**"同 schema 不同 LLM 实现"效果相当**——说明 alpha 质量由 schema 决定,不由模型决定
- **我的反思**:**AlphaSchema 的 5 维 schema 跟 9/22 我学的"产业链传导路径"惊人一致**——下游事件 → 中游 context → 上游 qualities。任何 alpha 挖掘都可以用这种"事件 × 上下文 × 特征"框架统一
- **资料来源**:`arxiv.org/abs/2607.26642`

### 5. "Not All Factors Crowd Equally" [arXiv:2512.11913] — alpha decay 的双曲函数实证
- **作者**:Chorok Lee (2025-12-11)
- **核心建模**:从博弈均衡推导 **alpha 衰减函数**:
  $$\alpha(t) = \frac{K}{1 + \lambda t}$$
  对比线性/指数衰减:**双曲衰减在动量因子上 R²=0.65**,明显胜出(线性 0.51,指数 0.61)
- **5 个核心发现**:
  1. **机械型因子**(动量、反转)→ 符合双曲衰减;**判断型因子**(价值、质量)→ 不符合
  2. **因子拥挤度自 2015 后加速**:OOS 模型 over-predict 0.30 vs 实际 0.15,与因子 ETF 规模增长高度负相关(rho=-0.63)
  3. **拥挤度对策略贡献**:仅靠"挤拥挤度低"选因子**不能**产生 alpha(Sharpe 0.22 vs 动量再动量 0.39)
  4. **拥挤度对风险贡献**:对!拥挤的 reversal 因子未来崩盘概率 1.7-1.8 倍;拥挤的 momentum 因子反而崩盘概率仅 0.38x
  5. **结论**:**拥挤度预测 tail risk 而非 means → 用于风控,不要用于 alpha**
- **这一发现颠覆的认知**:把"alpha 衰减"和"因子拥挤"绑在一起是大众误解——其实**alpha 的衰减是时间维度的(hyperbolic)**,**拥挤度是截面维度的(cross-sectional)**,二者机制不同
- **资料来源**:`arxiv.org/abs/2512.11913`

### 6. LLMFactor [arXiv:2406.10811] — 用 LLM 提取可解释股价因子
- **作者**:Meiyun Wang 等 (2024-06-16)
- **核心方法**:**Sequential Knowledge-Guided Prompting (SKGP)**:先做"填空式背景知识生成",再让 LLM 从新闻中提取"价格驱动因子",最后用因子预测股价运动
- **实证**:中美 4 个 benchmark 全部 SOTA
- **对比 2409.08282 "Which Voices Move Markets"**:分析师声音身份本身就能预测股价横截面
- **资料来源**:`arxiv.org/abs/2406.10811`

## 思考

### 思考一:AI 因子挖掘 = "LLM × DSL × AST × 正则化"的四元护栏

把上面 6 篇串起来,2026 年 AI 挖 alpha 的工程化方向已经清晰:

```
原始数据 (bar/orderbook/news)
   ↓
[DSL]: 把 LLM 输出限制到算子空间  ← Hubble
   ↓
[AST 沙箱]: 每个候选因子在沙箱中验证可执行 ← Hubble + AlphaAgent
   ↓
[LLM 翻译]: 把语义 schema 翻译为可执行代码 ← AlphaSchema
   ↓
[正则化]: 原创性 / 语义一致性 / 复杂度 ← AlphaAgent
   ↓
[残差化]: 对常见风格因子做回归再算 IC ← STRATA
   ↓
[双曲衰减建模]: 估计 alpha 的剩余生命周期 ← Lee 2025
   ↓
[风控而非选股]: 用拥挤度预测 tail risk,而非生成 alpha ← Lee 2025
   ↓
[家族多样性选择]: 不是按单一 IC 排序 ← Hubble
   ↓
最终 alpha 池
```

**这 9 步就是 2026 年 AI 量化的"流水线"**——比 9/22 我学的"传统六因子打分"已经复杂至少一个量级。

### 思考二:alpha decay 不是 alpha 死了,是 alpha 的"剩余生命周期"被精确定量了

Lee 2025 给了我**反直觉的实证**:
- alpha 服从 **hyperbolic decay** α(t) = K/(1+λt)
- 这意味着 alpha 衰减**越来越慢**(不是指数衰减的"急剧归零"),但**永不归零**
- 这与"动量再动量"的现象吻合:机械因子在初期下降快,后期拉长尾
- **实战含义**:当我们看到一个 alpha 失效,不应该全盘否定——而应该用 hyperbolic 估计"剩余生命周期",**设置过期预警**

### 思考三:拥挤度不是 alpha 的反向预测器,是 risk 的反向预测器

Lee 2025 同样颠覆认知:
- **拥挤的 reversal → 高崩盘概率**(1.7x)
- **拥挤的 momentum → 低崩盘概率**(0.38x)
- **结论**:拥挤度用于**尾部风险管理**,**不是 alpha 生成**

这给爸爸的实操含义:
- 当看到"低 PE 红利策略"被拥挤时 → 不应该"切换到价值"换 alpha,而应该**给低 PE 持仓加 crash protection**(如看跌期权/雪球对冲)
- 因为 alpha 已经被套利到接近 0,但 crash 风险很高

### 思考四:STRATA 用 Mamba 残差化 = 把"特征对抗"做到了极致

STRATA 的精妙在于:
- 不靠手工特征(位移到 end-to-end)
- 但用**8 个价量风格因子做残差化**,等于把"模型已经学到的风格信号"剥掉
- 这样 IC 是**纯模型信号的 IC**,不是"风格押注的 IC"
- **实战含义**:当我自己做策略回测时,**先回归风格因子再算 IC**——这个步骤最容易被忽视,但有效性提升 30-50%

### 思考五:AlphaSchema 的 5 维 schema = 通用 alpha 思维框架

AlphaSchema 用 5 个维度组织 alpha 空间:**{Event, Context, Qualities, Direction, Output}**。

这个跟 9/22 我学的"产业链传导路径"惊人对应:
- Event = 触发事件(财报/政策/订单)
- Context = 上下文(产业链环节)
- Qualities = 量价特征(动量/估值/波动)
- Direction = 方向
- Output = 输出形式

**这意味着任何 alpha 都可以用"事件 × 上下文 × 特征"的三维框架组织**——这是更高一层抽象。

### 思考六:Hubble 的"零运行时崩溃"是工业级硬约束

Hubble 用 AST 沙箱运行 104 个候选因子,**0 崩溃**——这在量化实战中是**生死线**:
- 任何在生产环境的因子失败 = 持仓不可执行 = 重大损失
- 这与 9/23 05:00 我学的硬件 BOM 解剖 + 量产工业理念一致:**做可观测、可诊断、可回退的系统**
- **给我的启发**:当爸爸问"这个因子能不能用"时,**永远先看是否被沙箱验证过**

### 我之前哪些理解是错的或片面的?
