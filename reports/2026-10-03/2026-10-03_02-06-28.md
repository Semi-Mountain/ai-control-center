## 1. 三篇核心论文

### 1.1 🏆 MemCodex: Self-Programming Hierarchical Memory for Language Agents
- **arXiv**: [2609.39765](https://arxiv.org/abs/2609.39765) (2026-09-30) · Xiaoqiang Wang, Bang Liu (Mila)
- **核心问题**：现有 agent memory 的"workflow 是 predefined" — 单一hop需要1条证据 vs 多跳需要"组合多源"，**没有设计空间让 agent 自己优化如何检索**
- **核心方案**：
  - 把 memory 组织成 **executable memory programs**（4 类：summaries / relational knowledge / reusable skills / latent memory）
  - **Open-ended program evolution** — 不只学"组合方式"，是 rewrite "每层的 build / index / retrieve / route"4 个环节
  - **MemArena runtime** — 统一接口
  - **Query-time**：coarse-to-fine 检索，"足够就停"
- **关键数字**：**+10.1%** 平均任务成功率 · **3.4x** 更少 context tokens · **2.1x** 更快 inference
- **核心引用**：
  > "Open-ended program evolution searches the open design space of layer programs by rewriting how each layer is constructed, indexed, retrieved, and routed, thereby adapting both within-layer implementations and cross-layer composition."

### 1.2 Safety Must Survive Self-Improvement
- **arXiv**: [2610.01073](https://arxiv.org/abs/2610.01073) (2026-10-01) · Yunbei Zhang et al. (CMU)
- **核心方案**：
  - **Paired interventions** — 拆分 3 个独立 trace：① 哪些 revision 通过 validation ② 哪个 program 在跑 ③ 编辑器下一步编辑哪个
  - **Stateful authorization testbed** — 故意让"先前测试通过的优化"被新授权依赖 invalidate
  - **Validating rollback** — 必要时回滚到 previous correct version
- **关键数字**：
  - **22/48 (45.8%)** framework histories 即使有正确替代方案，仍保留 unsafe programs
  - 即使"全 reject + failed incumbent 留任"也会持续失败
  - **Full validation + validated rollback = 100% correct programs + 保留 43% deployment savings**
- **核心引用**：
  > "Preserving agent safety requires checking what will run under current conditions and choosing which implementation to edit next."

### 1.3 GUI-HARVEST: Self-Improving GUI Agents through Evidence-Driven Harness Evolution
- **arXiv**: [2610.00948](https://arxiv.org/abs/2610.00948) (2026-09-30) · Geyi Yang et al.
- **核心方案**：
  - **Evidence-driven diagnosis** — 把 model outputs / executed actions / before-and-after screenshots 对齐
  - **Within-task joint evidence** — 同任务重复跑视为 joint evidence unit
  - **Recurring failure patterns → bounded source-code edits** — 用 prediction-before-evaluation 验证
- **关键数字**：
  - **6 个 backbone** 一致 improvement
  - **Qwen3-VL-32B-Instruct +12.33 points** on full suite
  - **Frozen-harness transfer improves GPT-5 by 13.87 pp** on WindowsAgentArena @ 50 steps **without further optimization**
  - **超过 Self-Harness 和 Meta-Harness**
- **核心引用**：
  > "GUI-HARVEST outperforms Self-Harness and Meta-Harness, suggesting that GUI-specific diagnosis and validation help harness improvements generalize to unseen tasks."

### 1.4 🔒 Safety in Self-Evolving Agents: A Survey（补充）
- **arXiv**: [2610.00093](https://arxiv.org/abs/2610.00093) (2026-09-08, 80 pages) · Jiahao Chen et al. (Zhejiang University + 28 authors)
- **SAVER 框架**：Substrate（reusable influence 定位）/ Adaptation（怎么变化）/ Violation（safety compromise）/ Exposure（failure可见点）/ Response（containment/repair/revocation）
- **核心引用**：
  > "Self-evolving agent safety therefore asks not only whether a response is aligned or an action authorized, but whether safety properties survive the accumulation, generalization, and cross-context reuse of locally useful experience."

## 2. 三大洞察

### 2.1 「Memory program is the unit of evolution」（最关键）
- MemCodex 核心洞见：**"memory 不是 data，是 executable program"** — 4 类 program（summary / relational / skill / latent）每个都自带 build/index/retrieve/route 元数据
- 含义：wowzai `memory.json` 是 **data**（key-value），不是 program（带元数据 + 可自演化）

- 含义：wowzai 现有 `learning_notes_*.md` 是单条 trace — 看不到"这次 prompt 改了之后下次又会改什么"

- GUI-HARVEST 核心洞见：**frozen backbone + 优化 harness** 也能赢大模型
- 含义：wowzai 不需要等"模型升级"才能变强 — **harness 自我优化** 就能让现有模型发挥更大能力
