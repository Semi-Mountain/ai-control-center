# 腾讯财经股票数据

> 基于腾讯财经API获取A股实时行情，无需API key，直接HTTP请求

## 数据源

- **接口**: `https://qt.gtimg.cn/q={stock_codes}`
- **优点**: 免费、无需API key、稳定、响应快
- **数据**: 实时行情（含开盘/最高/最低/现价/成交量等）

## 股票代码格式

- 上交所: `sh000001` (sh + 6位代码)
- 深交所: `sz000001` (sz + 6位代码)
- 爸爸的持仓示例:
  - `sh000001` - 上证指数
  - `sz000988` - 华工科技
  - `sh600118` - 中国卫通
  - `sz000582` - 北部湾港

## Python调用示例

```python
import requests

def get_tencent_quote(codes):
    """
    获取腾讯财经实时行情
    
    Args:
        codes: 股票代码列表，如 ['sh000001', 'sz000988']
    
    Returns:
        dict: {代码: {'name': 名称, 'price': 现价, 'change': 涨跌, 'pct': 涨跌幅, ...}}
    """
    # 拼接代码
    code_str = ','.join(codes)
    url = f'https://qt.gtimg.cn/q={code_str}'
    
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
        'Referer': 'https://finance.qq.com'
    }
    
    result = {}
    try:
        r = requests.get(url, headers=headers, timeout=10)
        
        for line in r.text.split(';'):
            if '\"' in line:
                data = line.split('"')[1].split('~')
                if len(data) > 30:
                    code = data[2]
                    result[code] = {
                        'name': data[1],           # 名称
                        'price': float(data[3]),   # 现价
                        'prev': float(data[4]),    # 昨收
                        'open': float(data[5]),    # 开盘
                        'high': float(data[6]),    # 最高
                        'low': float(data[7]),     # 最低
                        'volume': int(data[8]),   # 成交量(手)
                        'amount': float(data[9]),  # 成交额(元)
                        'change': float(data[3]) - float(data[4]),  # 涨跌
                        'pct': (float(data[3]) - float(data[4])) / float(data[4]) * 100,  # 涨跌幅%
                        'time': data[30]           # 时间
                    }
    except Exception as e:
        print(f"获取腾讯行情失败: {e}")
    
    return result

# 使用示例
if __name__ == '__main__':
    codes = ['sh000001', 'sz000988', 'sh600118', 'sz000582']
    data = get_tencent_quote(codes)
    
    for code, info in data.items():
        print(f"{code} {info['name']}: 现价{info['price']:.2f} 涨跌{info['change']:+.2f} 涨幅{info['pct']:+.2f}%")
```

# 金融数据查询

## 功能范围

### 1. 支持查询的对象范围

* 股票（A 股、港股、美股）
* 板块、指数、股东
* 企业发行人、债券、非上市公司
* 股票市场、基金市场、债券市场

### 2. 支持查询的数据类型

支持查询以下类型的结构化数据：

* **实时行情**（现价、涨跌幅、盘口数据等）
* **量化数据**（技术指标、资金流向等）
* **报表数据**（营收、净利润、财务比率等）

### 3. 查询方式与处理逻辑

统一使用 `--query` 传入自然语言问句（包含实体与指标），并使用 `--indicators` 传入从问句中提取的金融指标等关键信息。Skill 会先对 query 做实体识别，再按识别结果选择查数路径：

* **识别实体数 ≤ 5**：直接查数
* **识别实体数 > 5**：批量查数，最多处理识别结果中的前 **500** 个有效实体，如需大于500个实体，可分批多次调用

注意：当用户问句中只包含代词，需结合上下文或者提供文件读取所有实体名称，一并输入query。

#### `--indicators` 参数说明

调用本 Skill 前，需根据 `--query` 从用户问句中提取需要查询的**金融指标**（或指标组），填入 `--indicators`：

* 只填指标和时间范围等除实体外所有有效信息，不含实体名称等修饰语。
* 多个指标用用户原话拼接，如 `市盈率(动)和总市值`、`涨跌幅`、`营收、毛利、净利`。
* **不要在 `--indicators` 里重复写实体**。
* **尽量用用户原话表述，不要二次改写**。

> **示例**  
> 用户问「查询贵州茅台、五粮液近一年营收」  
> → `--query "查询贵州茅台、五粮液近一年营收" --indicators "近一年营收"`  

> 用户问「这批股票的涨跌幅是多少」或列出 6 只以上股票  
> → `--query "查询 A、B、C、D、E、F 六只股票的涨跌幅、pe、市值" --indicators "涨跌幅、pe、市值"`  

### 4. 输出结果

Skill 执行后会输出两个文件：

- **Excel（.xlsx）**：多 sheet 结构化数据表，数值为 `rawTable` 原始单位（金额为元、量为股等）；无 `rawTable` 时回退 `table`
- **Markdown（.md）**：使用接口 `table` 字段的展示数据（万/亿/万亿、% 等）；无 `table` 时回退为 `rawTable` 格式化结果
- 当 `table` 与 `rawTable` **数据量不一致**时，Markdown 文首及对应表下会标注：**本文件仅为部分展示数据，完整数据见 Excel**

## 常用接口

### 1. 登录/登出
```python
import baostock as bs

```

### 2. 获取股票基本信息
```python
rs = bs.query_stock_basic(code_name="华工科技")
```

### 3. 获取历史K线
```python
rs = bs.query_history_k_data_plus(
    "sz.000988",  # 股票代码
    "date,code,open,high,low,close,volume,turn",
    start_date='2026-09-01',
    end_date='2026-09-21',
    frequency="d",  # d=日线, w=周线, m=月线
    adjustflag="2"  # 2=前复权
)
```

### 4. 指数行情
```python
# 上证指数: sh.000001
# 深证成指: sz.399001

    "sh.000001",
    "date,open,high,low,close,volume",
    start_date='2026-09-18',
    end_date='2026-09-21'
)
```

### 5. 实时行情（单股票）
```python
rs = bs.query_zz_stock_quotes(code="sz000988")
while rs.next():

```

## 代码模板

```python
import baostock as bs
import pandas as pd

lg = bs.login()
if lg.error_code != '0':
    raise Exception(f"Baostock登录失败: {lg.error_msg}")

try:
    rs = bs.query_history_k_data_plus(
        "sz.000988",
        "date,code,open,high,low,close,volume",
        start_date='2026-09-18',
        end_date='2026-09-21',
        frequency="d",
        adjustflag="2"
    )
    
    data_list = []
    while rs.error_code == '0' and rs.next():
        data_list.append(rs.get_row_data())
    
    df = pd.DataFrame(data_list, columns=rs.fields)
    print(df)
    
finally:
    bs.logout()
```
